# 相对优势研究库

这是一个证据导向的个人研究库，用于长期识别你的“相对优势”：相对相关参照人群、也相对自己的平均表现，更自然、更可持续、更容易产出高质量结果的稳定模式。

## 核心原则

- 先看真实行为，再谈结论。
- 喜欢不等于擅长，做得多也不等于做得更强。
- 单一案例和单一测试都不能直接定义优势。
- 结论必须能追溯到任务、动作、结果、反馈和对比。
- 每条候选优势都要写明边界和替代解释。
- AI 或其他工具是表现场景，不默认等于优势本体。
- 证据不足时宁可保留疑问，也不要抢结论。

## 文件职责

- `AI-ENTRY.md`：默认入口，给 AI 的最短工作说明。
- `profile/baseline.md`：稳定背景、参照系和已知边界。
- `synthesis/current-map.md`：当前最像真的模式、开放问题和下一步动作。
- `hypotheses/candidate-strengths.md`：候选优势清单、边界和置信度。
- `evidence/raw-log.md`：快速记录池，默认写短卡。
- `evidence/episodes/`：少量升级后的高价值证据卡。
- `盖洛普才干报告-英文版.md`：参考材料，只能当假设线索，不能直接当结论。

## 更新流程

1. 先把新信息记成短卡，尽量只写事实。
2. 判断它支持的是行为、结果、对比中的哪一类信号。
3. 给出至少一个候选优势和至少两个替代解释。
4. 只在证据足够时更新综合判断，不把弱信号写成定论。
5. 标出下一条最值得补的证据。

## 协作风格

希望 AI / 他人扮演研究合作者，而不是顺着自我叙事的助理：

- 先分清事实、解释和假设。
- 主动指出跳跃、夸大或混淆。
- 证据不足时直接说“目前不能下结论”。
- 优先帮助我接近真实，而不是只让我感觉被认可。
