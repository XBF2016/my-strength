# 原始口述材料库

这个仓库的默认目标，不是提前固化“我的优势结论”，而是把你的口述内容尽量客观地转成结构化材料，便于以后交给更强的 AI 或其他工具重新分析。

换句话说，这里优先保存的是可复用的原始资料层；分析层可以存在，但必须和原始资料分开，并且默认不作为入口。

## 基本原则

- 先保留事实，再谈解释。
- 结构化的目的，是方便检索、比较和重算，不是提前下结论。
- 原始资料层只记录你明确说过的内容，以及能追溯到的背景、动作、结果和反馈。
- 没被明确说出的内容，不要为了“完整”而擅自补齐。
- 不确定就明确写“不确定”，不要把推测写成事实。
- AI 或其他工具是场景信息的一部分，不默认等于优势本体。
- 分析结论是可更新、可丢弃、可重算的，不应反过来污染原始资料层。

## 目录职责

- `AI-ENTRY.md`：给 AI 的默认入口说明，强调先读原始资料层。
- `profile/baseline.md`：稳定背景、参照系、已知经历和待补信息，只保留基线事实。
- `evidence/raw-log.md`：快速记录池，默认先记短卡，不做展开分析。
- `evidence/episodes/`：从短卡升级出来的结构化案例卡，仍以事实和原话为主。
- `analysis/current-map.md`：某一阶段的分析快照，不是事实层。
- `analysis/candidate-strengths.md`：某一阶段的候选假设，不是事实层。
- `盖洛普才干报告-英文版.md`：外部参考材料，只能作为线索来源，不能直接当结论。

## 默认工作流

1. 先把口述内容整理成结构化记录，尽量忠实保留原意。
2. 优先记录时间、背景、任务、动作、结果、反馈、原话和不确定点。
3. 重要材料再升级成案例卡，但仍放在原始资料层，不混入结论。
4. 只有在明确需要分析时，才把解释、假设和阶段性判断写进 `analysis/`。
5. 新模型或新工具进入时，默认先读取原始资料层，旧分析只作可选参考。

## 协作要求

希望 AI / 他人在这里扮演“结构化整理者”优先，“分析者”其次：

- 先分清事实、解释和假设。
- 默认不要沿用旧分析去改写新材料。
- 如果需要分析，应明确标注“这是分析，不是事实”。
- 如果引用某个判断，尽量指出它来自哪些原始卡片。
- 如果材料不足，直接保留空白，不强行补结论。
