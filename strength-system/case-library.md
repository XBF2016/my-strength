# 独特优势案例库

## 固定定义

独特优势只按这 3 个标准判断：

1. 长期可持续
2. 学习速度更快
3. 做得更好且有外部验证

## 记录模板

```markdown
## 正式案例 00X - 案例标题

- 日期: YYYY-MM-DD
- 来源: 用户口述案例
- 长期可持续性评分: 0-2
- 学习速度评分: 0-2
- 外部验证评分: 0-2
- 初步判断: strong signal | possible signal | insufficient evidence

### 事实

### 长期可持续性信号

### 学习速度信号

### 结果与外部验证

### 备注
```
