# Output Templates

Use these templates when applying `$structure-oral-material`.

## Short Card

Use for quick capture, rough oral recall, or material that should go to `evidence/raw-log.md`.

```md
- 日期：
- 场景 / 主题：
- 背景：
- 任务：
- 接收者：
- 初始信息 / 初始清晰度：
- 我的动作：
- AI / 工具参与：
- 结果：
- 外部反馈：
- 原话 / 证据出处：
- 仍不确定的点：
```

## Episode Card

Use for a richer single case, especially when material should go to `evidence/episodes/`.

```md
# 结构化案例卡：<标题>

- 日期 / 类型：
- 背景：
- 任务：
- 接收者：
- 初始信息 / 初始清晰度：
- 我的动作：
- AI / 工具参与：
- 结果：
- 外部反馈：
- 原话 / 证据出处：
- 仍不确定的点：
```

## Multi-Card Split

Use when one narration actually contains several distinct episodes.

```md
## 卡片 1：<主题>

- 日期：
- 场景 / 主题：
- 背景：
- 任务：
- 接收者：
- 初始信息 / 初始清晰度：
- 我的动作：
- AI / 工具参与：
- 结果：
- 外部反馈：
- 原话 / 证据出处：
- 仍不确定的点：

## 卡片 2：<主题>

...
```

## Optional Analysis Block

Add only when the user explicitly asks for analysis.

```md
## 可选分析（非事实）

- 基于以上材料，当前更像是在说明……
- 这部分仍缺少……
- 暂时不能直接推出……
```
